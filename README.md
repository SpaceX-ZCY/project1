# 俄罗斯方块游戏

一个使用HTML5 Canvas和JavaScript开发的经典俄罗斯方块游戏。

## 功能特点

- 🎮 经典的俄罗斯方块游戏体验
- 🎨 现代化的UI设计
- 📱 响应式设计，支持移动设备
- 🏆 计分系统和等级系统
- ⏸️ 暂停/继续功能
- 🔄 方块旋转和移动
- 🎯 行消除机制
- 👀 下一个方块预览

## 操作说明

- **← →** 左右移动方块
- **↓** 快速下降
- **↑** 旋转方块
- **空格键** 暂停/继续游戏

## 如何运行

1. 直接在浏览器中打开 `index.html` 文件
2. 或者使用本地服务器运行：
   ```bash
   # 使用Python简单服务器
   python -m http.server 8000
   
   # 或者使用Node.js
   npx serve .
   ```
3. 在浏览器中访问 `http://localhost:8000`

## 游戏规则

- 方块从顶部下降
- 使用方向键控制方块移动和旋转
- 当一行完全填满时会被消除
- 消除行数越多，得分越高
- 随着等级提升，方块下降速度会加快
- 当方块堆积到顶部时游戏结束

## 技术实现

- HTML5 Canvas 用于游戏渲染
- JavaScript ES6+ 语法
- CSS3 现代化样式设计
- 响应式布局适配不同屏幕尺寸
